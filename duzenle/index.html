Slaytlar

    Metinlerde **kalın**, *italik* ve -> (ok) yazabilirsiniz. Değişiklikler bu bilgisayarda taslak olarak saklanır; yayınlamak için Kaydet ve yayınla.

    Ayarlar

    Kaydedince değişiklikler doğrudan GitHub'daki siteye yazılır ve 1–2 dakika içinde yayına girer. Bunun için bir kez GitHub anahtarı (token) girmeniz gerekir. Anahtar yalnız bu tarayıcıda saklanır; ortak bilgisayarda kullanmayın.

    1. github.com/settings/personal-access-tokens/new sayfasını açın.
    2. Ad verin, süre seçin. Repository access: Only select repositories → lam-basinda.
    3. Permissions → Repository permissions → Contents: Read and write. Generate token.
    4. Çıkan anahtarı aşağıya yapıştırın.
